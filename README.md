# Koyomi カレンダー（カスタマイズ版）

## はじめかた
1. ZIPを解凍します。
2. `index.html` をブラウザで開きます。
3. 「カレンダーを開く」から予定を登録できます。

## 実装済み
- 月表示カレンダー、今日へ移動、前月・次月
- 予定の追加・編集・削除
- 日付、時刻、終日、カテゴリ、色、場所、メモ
- 予定検索、今後の予定一覧
- JSONバックアップ・読み込み、ICS書き出し
- テーマカラーのプリセット8色・自由な色選択
- 背景写真のアップロード・解除、透明度・ぼかし調整
- 文字サイズ、土日の色分け、前後月の日付、コンパクト表示、週の開始曜日
- 設定と予定のブラウザ内保存（写真はIndexedDB）

## 現在の制限
これはサーバー接続前のフロントエンド版です。データは基本的に利用中のブラウザ／端末に保存されます。
ログイン、Googleログイン、複数端末同期、リアルタイム共有、招待リンク、メンバー権限、通知のサーバー配信、天気・AI連携はまだ実装されていません。これらには認証・データベース・サーバー処理の追加が必要です。
写真とテーマ設定はJSON予定バックアップには含まれません。ブラウザのデータを消す前に予定をJSONで書き出してください。

## 公開する場合
複数人で安全に使う完成サービスにするには、Supabase等の認証・データベース・リアルタイム機能を接続し、アクセス権限やデータ保護を設定する必要があります。秘密鍵やパスワードをHTML/JavaScriptに直接書かないでください。
